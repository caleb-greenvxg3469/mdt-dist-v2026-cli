## What MDT Dist Is

MDT Dist is a Python command-line utility focused on marginal-data transport distillation for 3D generation pipelines. Its main objective is to lower the number of sampling steps required at inference time, helping workflows run more efficiently while remaining practical across platforms.

The repository is aimed at people working with machine learning tooling, 3D generation experiments, or CLI-first automation. Rather than a graphical application, it emphasizes compact model inference and repeatable, scriptable workflows.
